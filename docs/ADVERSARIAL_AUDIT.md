# Adversarial package audit — 2026-10-10

Status: corrections are uncommitted for review. This report inventories the whole Python package, tests, scripts and post-processing, with focused adversarial investigation of scientific and runtime boundaries. It does **not** certify every algorithm or claim total regression coverage. See `ADVERSARIAL_COVERAGE.md` for every source module and measured gaps, and `audit_evidence/validation.json` for the final test result.

## Architectural answers

### Sample accounting and transaction boundaries

`core/runtime/environment.py:Environment._apply_decision` owns execution, while `core/managers/budget.py:BudgetManager` owns counters and enforcement. `BudgetSpec.samples=None` means unlimited, **not uncounted**. The manager increments `samples_used` and `experiments_used` after an acquisition succeeds; `samples_left=None` cannot by itself communicate consumption. Artifacts also retain each batch's `n` and data. Reference samples generated by mission/metric mounting do not pass through this agent-acquisition budget; this is intentional evaluator work. Direct calls to `SCM.generate_samples` are also outside the environment's budgeting boundary.

All requested experiments are validated and preflighted before execution. Previously, a backend exception in a later experiment left earlier RNG draws consumed but committed no charge. The author's explicit policy is now **rollback the whole acquisition**. The environment stages copies of affected per-intervention RNG streams, validates returned row counts, and commits streams and sample/experiment/cost counters only after every experiment succeeds. Tests inject failure *after* draws in the second batch, verify unchanged counters and RNG state, then compare a retry with a fresh execution. Both repeated and distinct arms, and fresh and previously used streams, are tested.

This transaction covers environment-managed sample streams and accounting. Arbitrary external side effects inside third-party sampling plugins cannot be undone by copying RNGs. A failed call invalidates the game; callers constructing a new game get fresh components. CPU spent on an unsuccessful call is not rolled back. Memory accounting remains accumulated returned DataFrame size, not process RSS. Agent time remains a soft call-boundary limit.

Financial pricing now uses decimal arithmetic at calculation/accumulation boundaries so `3 × 0.1` fits `0.3`, independently of batching. Public counters remain floats for the existing DTO/JSON interface.

### BN domain persistence and isolation

`scm/nodes/bn.py:BayesianNetworkSCMNode` stores category **order** in `domain` and probabilities in `probability_distribution`. `core/contracts/scm_node.py:SCMNode.to_spec` writes `domain`, `parents`, access, mappings and serialized node RNG; BN `_to_dict` adds its CPT. `SCMNodeSpec` explicitly types both domain and probability data. `BayesianNetworkSCMNode.from_spec` reconstructs these fields; `SCM.from_spec` preserves a nonempty declared parent order rather than substituting graph edge order. The SCM checks CPT assignment completeness against parent domains.

There is no global BN domain registry. However, the constructor previously retained caller-owned domain and parent lists, and `get_distributions` returned live CPT row lists. Mutating either could change a live model without validation. Those configuration inputs and lookup outputs are now copied. Mixed integer/float parent columns previously went through a homogeneous NumPy matrix, changing `0` into `0.0` and breaking the key `"0,1.5"`; tuple iteration preserves scalar types. Categorical domains now require string labels, so mixed numeric/string categorical domains are rejected instead of being coerced during sampling. Numeric parent values remain type-preserving for CPT lookup.

Tests establish ownership isolation, deterministic CPT semantics, mixed-type parent-key lookup, and continuation of a **node's** serialized RNG without sharing it. Fresh `Game` construction isolates SCM domain configuration. These results do not imply a fully immutable public model: `node.domain`, `node.probability_distribution` and `scm.dag.graph` remain mutable public attributes. Nor is an SCM specification a complete mid-episode checkpoint: SCM `_sampling_streams` and environment per-arm streams are not serialized by `SCM.to_spec`. A full checkpoint/restart contract remains open and must not be inferred from configuration round-trip equality.

### `post-inform-v2` and schema versioning

`ArtifactWriter.write_provenance` writes the protocol identifier in `provenance.json`. It labels the execution semantics: acquire samples → inform agent → obtain its current answer → evaluate that answer. It is not an execution mode switch and did not itself change data schemas. Forced stops request a final response; missing, invalid or failed responses have no score, and must not inherit an earlier estimate.

The separate transcript `schema_version="2.0.0"` describes the current wire representation: explicit terminal reason/forced-stop/response status, final feedback and score status, budget fields, structured graph results, entries and acquisition data. Unsupported objects are explicitly lossy descriptors. It does not reconstruct arbitrary answer callables.

Before this audit, the label was written but publication analysis did not validate it. New `core/infrastructure/artifact_contract.py:validate_publication_transcript` checks supported protocol/schema, identity, round ordering, serialized sample counts/kinds, finite scores, terminal markers and final/terminal-entry consistency. `scripts/analyze_publication.py` calls this guard before exporting current publication figures. Real sequential/thread/process runner artifacts are checked against it. Legacy generic plotting remains a separate permissive reader; no silent migration or relabeling was introduced. This is an integrity validator for completed publication transcripts, not a complete JSON Schema implementation or cryptographic authenticity proof.

## Test quality audit

- `tests/unit/contracts/scm/test_scm.py:test_data_generation` passed a DataFrame positionally as `interventions`. With empty columns the old code silently did no intervention. Corrected to the documented keyword API. This was a real misuse masked by permissive implementation.
- `test_scm_node`, `test_scm`, `test_noise`, `test_metric` and other contract suites used module-scoped mutable instances. These fixtures now have function scope to avoid order-dependent RNG/model state. This does not by itself establish that every class has behavioral tests.
- Many generic contract tests compare `to_dict()` before/after reconstruction or identical seeded outputs. These are useful serialization/determinism checks, **not** evidence that either implementation is scientifically correct. Added independent deterministic-CPT and analytical-moment checks instead of deleting useful round-trip tests.
- `tests/unit/managers/test_budget.py:test_simulate_dataframe_memory_shape_and_dtype` tests a test helper's shape, not a production budget invariant. It contributes no evidence of budget correctness; retain or remove separately without treating its pass as hardening evidence.
- Existing `charge_samples(-4)` and `charge_memory(-128)` tests encode the current public no-op convention. Runtime experiment counts are positive DTO fields, but direct negative charging calls remain accepted. Decide whether to deprecate this public convention before rewriting tests around rejection.
- `tests/unit/agent/test_authoritative_inferers.py` mocks upstream calls. It validates adapter orientation/arguments and dependency errors, not algorithm accuracy. Real backend integration tests provide separate evidence; dependency-absent `importorskip` paths can otherwise give a misleading green run. Final audit execution records the actual skip count.
- Dynamic subclass discovery in contract suites can produce empty parametrizations if discovery breaks. An explicit supported-class inventory and collection-count guard remain missing.
- No literal `assert True` was found in the reviewed tests. Assertions such as `is not None` were reviewed in context rather than automatically declared tautologies.
- Red-phase lifecycle evidence contains one audit-test authoring error (wrong fixture domain `[0,1]` versus its declared `[-1,1]`); it was corrected and is **not** counted as a package defect. The initial causal test's mistaken factory name was corrected before the preserved causal red-phase log. Reports must not inflate defect counts with these mistakes.

## Adopted categorical label contract — 2026-10-10

The author selected string labels for every categorical value, avoiding a new discriminated domain type. `SCMNode` enforces unique strings for categorical subclasses, while `SCMNodeSpec` rejects numeric domains for the built-in categorical classes before model construction. `dataset_scm` stringifies columns explicitly designated categorical in both stored records and domains, and rejects collisions such as integer `1` and string `"1"`. BIF and bundled categorical assets already use string labels; the bundled manifest scan found no numeric categorical domains. `ExhaustiveDecider` and `RandomDecider` enumerate/sample string categories, while numerical domains remain two-bound intervals sampled uniformly. Tests cover numeric-label rejection in specs and constructors, dataset conversion/collision, string-category reconstruction, three-category random/exhaustive actions, and categorical interventions. The 2026-10-10 post-adoption suite result is recorded in `audit_evidence/validation.json`.
